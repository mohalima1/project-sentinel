# Dashboard design

Mode: Operate. Favor quick status checks and clear account/session controls.
Use a light warm neutral canvas (#f5f6f3), white surfaces, dark ink (#172c29),
muted green (#375b4d), visible green focus rings, system sans-serif typography,
and tabular numerals. Content width 1120px, 24px page gutters, 8px spacing unit.
Login uses a focused labeled form; overview uses readiness rows followed by
actual activity. Mobile stacks columns and allows long values to wrap. No remote
fonts/assets, animation, fabricated charts, or decorative monitoring claims.
